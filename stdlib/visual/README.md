# lattice/std/visual

`title` is hosted as a Wasmtime WIT component. `callout` / `fade` / nested `opacity` are in-process builtins.

| Word | Effect |
|---|---|
| `title` | Generated text placement |
| `callout` | Second overlay, distinct from title |
| `fade` | Fade-in envelope on a source's video placement |
| `opacity` | Nested title body invocation (0–100) |
